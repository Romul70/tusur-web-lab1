# Лабораторная работа №1 — вариант 7
Разработка веб-приложения на Flask для перестановки каналов RGB.
Вариант: (20 × 38) div 100 = 7.

## Окружение и запуск
Нужен Python 3.12. Перейдите в каталог project.
```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```
В Windows: `py -3.12 -m venv .venv`, затем `.venv\Scripts\activate`.
Команда создания окружения и установка выполняются один раз; затем запускайте `python app.py`.
Проверки: `python -m unittest discover -v`.

## Подготовка размещения
`render.yaml` описывает сборку, запуск и проверку `/health`. `Procfile` содержит команду WSGI-сервера.
В дополнительной методичке (2023), стр. 26, допускается проверка изменений на локальной машине.
16.11.2026 приложение опубликовано на Render: https://tusur-web-lab1-d15u.onrender.com.
Публичные /health и /verify вернули HTTP 200, хэш проверен независимо.
Чтобы разместить самостоятельно: отправьте проект в свой репозиторий, подключите его в Render,
выберите Python 3.12, сборку `pip install -r requirements.txt` и команду из Procfile.
Платформа задаёт PORT; фактические значения секретов не включены в проект и отчёт.
Файл `.env.example` показывает переменные. Приложение читает переменные окружения,
но не загружает `.env` автоматически: задайте их в терминале или интерфейсе платформы.
Gunicorn предназначен для Linux/macOS; локальный `python app.py` работает также в Windows.

## Использование
Откройте http://127.0.0.1:5001. Выберите examples/gradient.png или свой PNG/JPEG/WebP,
порядок каналов и введите ответ на арифметическую CAPTCHA. При неверном ответе форма выдаст новую CAPTCHA.
Есть все шесть перестановок. Например, BGR переносит исходный B в новый R, исходный R в новый B.
После обработки доступны исходное/новое изображения, шесть графиков и загрузка результата в PNG, JPEG или WebP.
Гистограммы считают пиксели каждого уровня 0–255. Профиль X усредняет строки по каждому столбцу,
профиль Y — столбцы по каждой строке. Размер изображения сохраняется.
EXIF-ориентация учитывается; L и RGBA преобразуются в RGB, альфа-канал отбрасывается.
Ограничения: 8 МиБ, 4 миллиона пикселей; повреждённые и неподдерживаемые файлы отклоняются.
CAPTCHA одноразовая и действует 5 минут; ответы хранятся в памяти процесса.
Поэтому конфигурация Gunicorn использует один worker. SECRET_KEY задавайте стабильным случайным значением.
После перезапуска действующие CAPTCHA нужно обновить. Вычисления и изображения не сохраняются на сервере.

## Файлы реализации
app.py — маршруты, форма, CAPTCHA, проверки.
processing.py — преобразование, статистика и построение графиков.
templates/index.html, static/style.css — интерфейс.
test_app.py и test_revision.py — 10 тестов, включая пиксели, средние, конвертацию и /verify.
requirements.txt — зависимости. examples/gradient.png — воспроизводимый учебный пример.

Версии GitHub Actions сверены с официальными примерами: [setup-python](https://github.com/actions/setup-python), [checkout](https://github.com/actions/checkout).

## Доработка по рецензии от 14.11.2026
Добавлен выбор выходного формата PNG, JPEG, WebP. Для простой конвертации выберите RGB.
PNG и WebP сохраняются без потерь относительно RGB-результата, JPEG — с quality=95.
Прозрачность отбрасывается, как и в исходной версии; анимация не сохраняется.
Добавлен GET /verify с персональным токеном, датой сервера и X-Verify-Hash.
Нормализация выполняется строго по правилам руководителя.
Запуск всех 10 тестов: `python -m unittest discover -v`.
Проверка: `curl -i http://127.0.0.1:5001/verify`.
Независимая проверка хэша: `python check_verify.py http://127.0.0.1:5001/verify`.
